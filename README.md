# 프로젝트 개요

본 프로젝트는 **OpenCV**와 **MediaPipe Hand Landmarker**를 활용하여 웹캠만으로 조작할 수 있는 손동작 기반 미로 탈출 게임입니다.

사용자는 검지 손가락으로 START 버튼을 선택하고, 손가락 개수(1개, 2개, 3개)를 이용하여 난이도를 선택합니다. 이후 검지 손가락의 움직임을 이용하여 미로 속 빨간 점을 조작하며 출구까지 이동합니다.

기존의 키보드나 마우스를 사용하는 방식이 아닌 **비접촉식 인터페이스**를 적용하여 누구나 직관적으로 사용할 수 있도록 구현하였으며, 미로 탐색을 통해 집중력과 공간 지각 능력을 활용하는 인지 훈련 콘텐츠를 목표로 개발하였습니다.

# 🧪 개발 과정

### 1. 시작 화면 구현

웹캠 영상을 출력하고 검지 손가락이 START 버튼 영역에 들어오면 게임을 시작하도록 구현하였습니다.

---

### 2. 손가락 개수를 이용한 난이도 선택

MediaPipe가 제공하는 손 랜드마크를 이용하여 검지, 중지, 약지의 상태를 판별하였습니다.

* 1 Finger → EASY
* 2 Fingers → MEDIUM
* 3 Fingers → HARD

같은 손동작을 2초 동안 유지하면 난이도가 선택됩니다.

---

### 3. 손동작 기반 미로 조작

검지 손가락의 현재 위치와 이전 위치의 이동량(dx, dy)을 계산하여 미로 속 빨간 점을 이동하도록 구현하였습니다.

웹캠 좌표와 미로 이미지의 해상도가 서로 다르기 때문에 좌표를 미로 이미지 크기에 맞게 변환하여 정확한 위치에서 이동하도록 구현하였습니다.

---

### 4. 게임 로직 구현

* 입구 도착 시 게임 시작
* 벽 충돌 감지
* Life 감소
* 게임 시간 측정
* 출구 도착 시 GAME CLEAR
* Life가 모두 소진되면 GAME OVER

---

### 5. 게임 종료 화면

게임 종료 후 RESTART와 EXIT 버튼을 제공하며, 검지 손가락을 버튼 위에 2초 동안 유지하면 해당 기능이 실행됩니다.

# 🧩 트러블슈팅 경험

### 문제 1. 웹캠 좌표와 미로 좌표 불일치

**문제 상황**

웹캠에서 인식한 손 좌표를 그대로 미로에 적용하니 빨간 점이 실제 손 위치와 다르게 움직였습니다.

**해결 방법**

웹캠 해상도와 미로 이미지 해상도의 비율을 계산하여 좌표를 변환하였으며, 좌우 반전된 웹캠 화면을 고려하여 X축 좌표를 반전시켜 이동 방향을 일치시켰습니다.

---

### 문제 2. 손가락 인식이 순간적으로 변경되는 현상

**문제 상황**

손가락 개수가 순간적으로 잘못 인식되어 난이도가 의도하지 않게 변경되는 문제가 발생했습니다.

**해결 방법**

동일한 손동작이 2초 이상 유지될 때만 난이도를 확정하도록 구현하여 오인식을 줄였습니다.

---

### 문제 3. 벽에 닿았을 때 Life가 빠르게 감소하는 문제

**문제 상황**

벽에 계속 닿아 있는 동안 Life가 프레임마다 감소하여 게임 진행이 어려웠습니다.

**해결 방법**

벽에 처음 닿았을 때만 Life를 감소시키고, 1초의 쿨타임을 적용하여 연속 감소를 방지하였습니다.
